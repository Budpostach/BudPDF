# BudPdf Converter

Клієнтський вебдодаток для швидкого та безпечного поділу багатосторінкових PDF-документів на окремі сторінки, їх переведення у чорно-білий формат (Grayscale) та автоматичної оптимізації розміру файлів (менше ніж 490 КБ) для відповідності вимогам українських банків.

🌐 **Live Demo:** [budpdf.vercel.app/]
 
---

## 🚀 Основні можливості

* **Посторінковий поділ:** Автоматичне розбиття будь-якого багатосторінкового PDF-файлу на окремі односторінкові документи.
* **Автоматичний підбір роздільної здатності:** Динамічне тестування DPI (300, 200, 150, 100) та якості JPEG для гарантії того, що кожен фінальний файл важить менше ніж **490 КБ**.
* **Чорно-білий режим (Grayscale):** Поконверсійне переведення сторінок у якісний чорно-білий колір для зменшення ваги та вимог до сканів.
* **Інтерактивний попередній перегляд:** Зручний перегляд кожної конвертованої сторінки у модальному вікні перед завантаженням.
* **Гнучке завантаження:** Можливість завантажувати кожен аркуш окремо або всі файлом одразу в єдиному **ZIP-архіві**.
* **Повна конфіденційність:** Уся обробка виконується повністю локально у вашому браузері за допомогою `PDF.js` та `jsPDF`. Файли ніколи не завантажуються на зовнішні сервери.
* **Локалізація:** Інтерфейс повністю адаптований українською та англійською мовами.

---

## 🛠 Технологічний стек

* **HTML5 / CSS3 / JavaScript (ES6+)** — основна логіка та інтерфейс.
* **Tailwind CSS** — сучасний та адаптивний дизайн інтерфейсу.
* **PDF.js (v3.11.174)** — рендеринг та розбір PDF-документів на стороні клієнта.
* **jsPDF** — генерація та збірка нових оптимізованих PDF-файлів.
* **JSZip** — пакування та генерація ZIP-архівів для масового завантаження.
